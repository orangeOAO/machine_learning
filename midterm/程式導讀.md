# 報告前先讀懂這些程式

## 一張圖片如何變成預測？

`project.py` 的 `transform()` 把圖片縮成 160×160，轉為三通道 tensor，再用 ImageNet 的 mean/std 標準化。單張 shape 是 `[3,160,160]`，一批通常是 `[32,3,160,160]`。

`SmallCNN.forward()` 先經卷積特徵層，再經分類層。最後輸出 shape 是 `[batch_size,6]`，每列六個數字稱為 logits。`argmax(1)` 取分數最高的類別。

## Loss 與反向傳播

`run_epoch()` 使用 `cross_entropy(logits, y)`。`y` 是 0 到 5 的整數標籤，這個函式已包含 log-softmax，因此訓練前不要再對 logits 手動 softmax。

有傳入 optimizer 時，程式執行：

```python
optimizer.zero_grad()  # 清空上一批梯度
loss.backward()       # 計算 loss 對可訓練參數的梯度
optimizer.step()      # 用 AdamW 更新參數
```

驗證與測試沒有傳入 optimizer，也不計算梯度。`net.eval()` 關閉 CNN 的 Dropout，並使用 BatchNorm 已累積的統計。

## 為什麼 ResNet18 骨幹不會更新？

`build('resnet18', pretrained=True)` 載入 ImageNet 權重，把所有原有參數設為 `requires_grad=False`，再新建 `fc` 最後一層。新層的參數預設可以訓練。訓練時還會讓骨幹保持 eval，避免 BatchNorm 的 running mean/variance 被改變。

## 為什麼最佳模型不一定是最後一輪？

每個 epoch 結束後計算 validation macro F1。只有超過過去最佳成績才覆寫 `best.pt`。最後 `evaluate()` 載入 `best.pt` 評估完整測試集，因此曲線最後一點與簡報的測試結果可能來自不同 epoch。

## 如何讀 Loss 曲線？

- train 和 validation loss 都下降：目前有學到可泛化的規律。
- train loss 下降、validation loss 持續上升：可能有過擬合，要結合其他指標與資料量判斷。
- validation loss 單次跳動：不能只憑一個點斷言過擬合，也可能受小驗證集或訓練不穩定影響。
- train 與 validation 的計算條件不同：訓練有資料增強、CNN 有 Dropout，且權重在一輪內持續更新；驗證使用該輪結束後的固定模型。

## 最容易被問倒的三個地方

1. ResNet18 用了額外的 ImageNet 預訓練知識，因此不是兩個模型都只看過 TrashNet。
2. 本實驗只訓練 ResNet18 的最後分類層，不能說「完整微調 ResNet18」。
3. 正式準確率取自完整測試集，Demo 挑選的三張圖片只是例子。

## DNN-TC 比較版如何訓練？

`build('dnn_tc')` 使用 ResNeXt-101 32x8d，將 fc 改成 Linear(2048,1024)、ReLU、Linear(1024,6)。`train_dnntc.py` 暫時將 fc 改成 Identity，以固定的 eval 模式擷取 2048 維特徵。兩組隨機增強訓練特徵輪流供分類頭學習，驗證使用固定前處理。選好驗證 macro F1 最佳的分類頭後，將它接回骨幹並保存完整 checkpoint。

這是凍結骨幹的架構比較實作。論文的完整微調、224px 與 Adam/SGD 排程沒有在本次實驗重現，詳見 `DNN_TC_METHOD.md`。
